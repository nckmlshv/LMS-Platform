# GET /users → Сервис «Пользователи»
Спецификация обработки запроса GET /users в сервисе «Пользователи».<br>

## Назначение
Получение информации о пользователе

## Входные данные

| Path-параметр    | Тип данных | Обязательное | Описание                     |
|---------|------------|--------------|------------------------------|
| user_id | string     | Да           | Идентификатор пользователя   |


### Пример запроса

    GET /users/123
   
## Выходные данные

| Поле          | Тип данных | Обязательное | Описание |
|---------------|------------|--------------|----------|
| id            | integer    | Да           | ID пользователя |
| first_name    | string     | Нет          | Имя |
| last_name     | string     | Нет          | Фамилия |
| middle_name   | string     | Нет          | Отчество |
| email         | string     | Да           | Email |
| phone_number  | string     | Нет          | Телефон |
| role          | string     | Да           | Роль |
| avatar_url    | string     | Нет          | Аватар |
| creation_date | datetime   | Нет          | Дата и время создания |
| email_notifications | string     | Да           | all / important / no |
| created_at    | date       | Нет          | Дата создания |

### Пример ответа

    {
      "id": 123,
      "first_name": "Donald",
      "last_name": "Trump",
      "middle_name": "John",
      "email": "student@lms.com",
      "phone_number": "+71234567890",
      "role": "student",
      "avatar_url": "https://lms.com/avatars/1.png",
      "email_notifications": "all"
      "creation_date": "2025-08-30T14:30:00",
      "created_at": "2026-01-01"
    }

## Алгоритм работы сервиса «Пользователи»

1. Поиск совпадений в БД по полю id<br>
       - БД не вернула записи → Прекратить выполнение
       - БД вернула записи → Продолжить выполнение
2. Создать JSON-объект из записи БД
5. Вернуть ответ 200 OK

## Ошибки

### Формат ошибки

| Поле         | Тип данных | Описание |
|--------------|------------|----------|
| status_code  | integer    | HTTP-код |
| description  | string     | Описание ошибки |

### Пример ошибки

    {
      "status_code": 404,
      "description": "Not found"
    }

## Возможные ошибки

| Код | Описание |
|-----|----------|
400 | Некорректный user_id  
401 | Не авторизован  
403 | Доступ запрещён  
404 | Пользователь не найден  
500 | Ошибка сервера
