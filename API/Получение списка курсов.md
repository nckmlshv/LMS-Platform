# GET /courses → Сервис «Курсы»
Спецификация обработки запроса GET /courses в сервисе «Курсы».<br>

## Назначение
Получение информации о курсах

## Входные параметры

| Query-параметр   | Тип данных | Обязательное | Описание |
|--------|------------|--------------|----------|
| cursor | string     | Нет          | Курсор для получения следующей страницы. Для первого запроса не передаётся |
| limit  | integer    | Нет          | Количество элементов на странице (1–100, по умолчанию 20) |

### Пример запроса

    GET /сourses?limit=2
   
## Выходные данные

| Поле        | Тип данных | Обязательное | Описание |
|-------------|------------|--------------|----------|
| items       | array      | Да           | Список курсов на текущей странице |
| next_cursor | string     | Нет          | Курсор для следующей страницы. Если страниц больше нет, возвращается null |

### Пример ответа

    {
      "items": [

          "id": 1,

## Алгоритм работы сервиса «Курсы»

1. Валидация query-параметров<br>
       - БД не вернула записи → Прекратить выполнение
       - БД вернула записи → Продолжить выполнение
2. Создать JSON-объект из записи БД
5. Вернуть ответ 200 OK

## Ошибки

### Формат ошибки

| Поле         | Тип данных | Описание |
|--------------|------------|----------|
| status_code  | integer    | HTTP-код |
| description  | string     | Описание ошибки |

### Пример ошибки

    {
      "status_code": 404,
      "description": "Not found"
    }

## Возможные ошибки

| Код | Описание |
|-----|----------|
400 | Некорректный user_id  
401 | Не авторизован  
403 | Доступ запрещён  
404 | Пользователь не найден  
500 | Ошибка сервера
