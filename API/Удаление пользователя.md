# DELETE /users/{user_id} → Сервис «Пользователи»
Спецификация обработки запроса GET /users в сервисе «Пользователи»<br>

## Назначение
Удаление пользователя

## Входные данные

| Path-параметр    | Тип данных | Обязательное | Описание                     |
|---------|------------|--------------|------------------------------|
| user_id | string     | Да           | Идентификатор пользователя   |


### Пример запроса

    DELETE /users/123
   
## Выходные данные

| Поле         | Тип данных | Описание |
|--------------|------------|----------|
| status_code  | integer    | HTTP-код |
| description  | string     | Описание |

### Пример ответа

    {
      "status_code": 200,
      "description": "Пользователь удален",
    }

## Алгоритм работы сервиса «Пользователи»

1. Поиск совпадений в БД по полю id<br>
       - БД не вернула записи → Прекратить выполнение<br>
       - БД вернула записи → Продолжить выполнением<br>
2. Удалить записи каскадным методом<br>
5. Вернуть ответ 200 OK<br>

## Ошибки

### Формат ошибки

| Поле         | Тип данных | Описание |
|--------------|------------|----------|
| status_code  | integer    | HTTP-код |
| description  | string     | Описание ошибки |

### Пример ошибки

    {
      "status_code": 404,
      "description": "Not found"
    }

## Возможные ошибки

| Код | Описание |
|-----|----------|
400 | Некорректный user_id  
401 | Не авторизован  
403 | Доступ запрещён  
404 | Пользователь не найден  
500 | Ошибка сервера
