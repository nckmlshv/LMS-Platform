# USE CASES

## UC-1. Покупка курса / траектории обучения (оплата доступа к материалам курса / траектории обучения)

### Описание
Оплата курса / траектории обучения и получение полного доступа к материалам для старта обучения.

### Акторы
- Пользователь  
- Система

### Начальное состояние
1. Пользователь авторизован в Системе (есть персональный аккаунт).
2. Открыта страница выбора курсов или страница с деталями конкретного курса.

### Триггер
Нажатие кнопки **«В корзину»** у конкретного курса.

### Успешный сценарий
1. Пользователь добавляет выбранные курсы в корзину по нажатию кнопки **«В корзину»**.
2. Отмеченные курсы попадают в раздел **«Корзина»**.  
   Система отображает:
   - название курсов;
   - стоимость каждого курса;
   - полную стоимость;
   - скидку;
   - итоговую стоимость (после применения скидки).
3. Пользователь переходит в раздел **«Корзина»** и проверяет корректность выбранных материалов.
4. Пользователь нажимает кнопку **«Оплатить»**.
5. Система перенаправляет Пользователя на страницу оплаты.
6. После успешной оплаты Система открывает экран с сообщением об успехе и кнопкой **«Начать учиться»**.
7. Приобретённый курс появляется в разделе **«Мои курсы»**.
8. Система сохраняет информацию об оплате в разделе **«Покупки»**:
   - дата оплаты;
   - сумма оплаты;
   - перечень приобретённых материалов.

### Альтернативный сценарий
1. Если на момент нажатия кнопки **«В корзину»** Пользователь не авторизован:
   - Система отображает страницу авторизации;
   - после успешного входа перенаправляет в корзину с уже добавленными материалами.
2. При обнаружении ошибки в составе корзины Пользователь нажимает кнопку **«Удалить»** рядом с неверно выбранным курсом и удаляет его.
3. При наличии промокода Пользователь:
   - вводит его в соответствующее поле;
   - Система проверяет применимость промокода;
   - пересчитывает суммы с учётом скидки;
   - Пользователь нажимает **«Оплатить»**.

### Негативный сценарий
1. Если Пользователь пытается добавить в корзину курс, снятый с продажи, но отображаемый в каталоге:
   - Система отображает сообщение об ошибке;
   - курс не добавляется в корзину.
2. Если введённый промокод неприменим к части курсов:
   - Система отображает предупреждение;
   - пересчитывает суммы только для применимых курсов.
3. Если промокод полностью неприменим:
   - Система отображает ошибку;
   - суммы не пересчитываются.
4. В случае неуспешного платежа:
   - Система отображает страницу с ошибкой оплаты;
   - отображается кнопка **«Повторить оплату»**.

### Конечное состояние
1. Все курсы из корзины успешно оплачены.
2. Приобретённые курсы отображаются в разделе **«Мои курсы»**.
3. В разделе **«Покупки»** создана запись с информацией об оплате.
4. Пользователь может начать обучение немедленно.

## UC-2. Просмотр и изучение приобретённых материалов

### Описание
Просмотр и изучение ранее приобретённых образовательных материалов (курсов).

### Акторы
- Пользователь  
- Система

### Начальное состояние
1. Пользователь авторизован в Системе (есть персональный аккаунт).
2. У Пользователя есть ранее приобретённые материалы.
3. Открыта страница **«Мои курсы»**.

### Триггер
Нажатие на выбранный курс на странице **«Мои курсы»**.

### Успешный сценарий
1. После выбора курса Система предлагает варианты:
   - **Продолжить изучение**;
   - **Начать с начала**.
2. При выборе опции **«Начать с начала»** Система открывает страницу навигации по курсу со стартового экрана.
3. На стартовом экране отображаются:
   - структура курса (этапы);
   - прогресс-бар;
   - область с учебными материалами (видео, фото, тексты, файлы);
   - кнопки навигации;
   - кнопка **«Поддержка»**;
   - чат с куратором;
   - раздел **«Комментарии»**.
4. При переходе на последний этап курса открывается страница получения сертификата.
5. Пользователь:
   - скачивает сертификат по кнопке **«Скачать»**;
   - вводит электронную почту;
   - нажимает кнопку **«Отправить»**.
6. После выпуска сертификат сохраняется в разделе **«Достижения»**.
7. Курсу присваивается статус **«Завершён»**.

### Альтернативный сценарий
- Если Пользователь не авторизован при открытии раздела **«Мои курсы»**:
  - Система перенаправляет на страницу авторизации;
  - после успешного входа открывает раздел **«Мои курсы»**.
- При выборе опции **«Продолжить изучение»**:
  - Система открывает курс с последнего завершённого этапа.
- Если Пользователь прерывает обучение:
  - Система сохраняет текущий этап;
  - при следующем входе курс открывается с этого этапа.
- В процессе обучения Пользователь может:
  - оставлять отзывы;
  - отвечать на отзывы других пользователей.

### Негативный сценарий
1. Если Пользователь пытается открыть курс, доступ к которому был отозван (например, из-за возврата средств или ошибки оплаты):
   - Система отображает сообщение об отсутствии доступа к курсу;
   - Пользователь не может перейти к материалам курса.
2. Если в процессе загрузки учебных материалов (видео, файлы, изображения) возникает ошибка:
   - Система отображает уведомление об ошибке загрузки;
   - Пользователю предлагается повторить попытку или обновить страницу.
3. Если соединение с сетью прерывается во время прохождения курса:
   - Система отображает сообщение о потере соединения;
   - прогресс текущего этапа не фиксируется до восстановления соединения.
4. Если Пользователь пытается перейти к следующему этапу курса, не завершив обязательные предыдущие этапы:
   - Система отображает предупреждение о необходимости завершения предыдущего этапа;
   - переход к следующему этапу блокируется.
5. Если при выпуске сертификата возникает техническая ошибка:
   - Система отображает сообщение о невозможности сформировать сертификат;
   - Пользователю предлагается повторить попытку позднее или обратиться в поддержку.
6. Если Пользователь вводит некорректный адрес электронной почты при отправке сертификата:
   - Система отображает сообщение об ошибке валидации;
   - Отправка сертификата не выполняется до исправления данных.

### Конечное состояние
1. Курс успешно пройден.
2. Курсу присвоен статус **«Завершён»**.
3. Выпущен сертификат о прохождении.
4. Сертификат добавлен в раздел **«Достижения»**.
